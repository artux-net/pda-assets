# Локализация ассетов

Строковые ресурсы игры хранятся в `locale/` и `templates/` как обычные Java `.properties`/текстовые файлы.
Конвенция именования локалей — суффикс `_en` к базовому имени файла (без локали = русский, исторически
основной и единственный язык проекта):

| Файл (RU, база) | Файл (EN) | Назначение |
|---|---|---|
| `locale/ui.properties` | `locale/ui_en.properties` | Строки интерфейса ПДА |
| `templates/actions` | `templates/actions_en` | Фразы-события для генератора случайных сообщений/слухов |
| `templates/locations` | `templates/locations_en` | Фразы-привязки к месту для того же генератора |
| `templates/names` | `templates/names_en` | Имена случайно генерируемых NPC-одиночек (транслитерация) |
| `templates/nicks` | `templates/nicks_en` | Позывные NPC (перевод по смыслу, как в официальной локализации S.T.A.L.K.E.R.) |

## Важно: `templates/messages` — производный файл, не редактируется вручную

`templates/messages` (4436 строк) — это заранее просчитанный набор комбинаций `templates/locations` ×
`templates/actions` ("Видел сегодня <локация> <событие>."). Скрипта, которым он был сгенерирован, в
репозитории не найдено, поэтому английская версия `templates/messages` руками **не создавалась** — переводить
4436 почти дублирующихся строк вручную было бы избыточно и создало бы риск рассинхронизации с
`actions`/`locations` при следующем изменении контента.

Если игра действительно грузит именно `templates/messages` напрямую (а не собирает сообщение во время
выполнения из `actions` + `locations`), для англоязычной версии нужно либо восстановить генератор и
прогнать его на `actions_en`/`locations_en`, либo (что вероятнее и правильнее) поменять код так, чтобы
сообщение собиралось на лету из двух переведённых файлов — так же, как это, судя по всему, происходит в
рантайме сейчас. Уточнить у разработчиков `pda`, какой из двух сценариев верный — это отдельный вопрос вне
периметра ассетов.

## Почему `names`/`nicks` переведены по-разному

- `templates/names` — реальные славянские имена (Илья, Богдан...) → **транслитерация** в латиницу
  (Ilya, Bogdan...), так как это не переводимые слова, а собственные имена.
- `templates/nicks` — позывные сталкеров (Лютый, Снайпер, Кислый...) → **перевод по смыслу**
  (Fierce, Sniper, Sour...), по аналогии с официальной английской локализацией серии S.T.A.L.K.E.R., где
  позывным-кличкам подбирались смысловые аналоги, а не транслитерация.
